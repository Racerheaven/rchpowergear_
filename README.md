# RCH Powergear — Premium Website

Website katalog apparel custom dengan tema hitam-emas, dibuat menggunakan HTML, CSS, dan JavaScript biasa. Tidak perlu instal Node.js atau framework.

## Cara membuka di VS Code
1. Ekstrak `RCH-Powergear-VSCode.zip` ke folder pilihanmu.
2. Buka VS Code.
3. Pilih **File → Open Folder...** lalu pilih folder `rch_project` (atau folder hasil ekstrak).
4. Buka `index.html`.
5. Untuk melihat website, klik kanan `index.html` lalu pilih **Open with Live Server** jika ekstensi Live Server sudah terpasang. Bisa juga buka `index.html` langsung dari File Explorer/Finder di browser.

## Sebelum dipakai pelanggan
- Buka `index.html`, cari `const WHATSAPP_NUMBER = '6281234567890';` lalu ganti dengan nomor WhatsApp bisnis. Gunakan kode negara 62, tanpa tanda `+` dan tanpa angka 0 di depan.
- Tambahkan foto produk milik RCH ke folder `images/` dengan nama file berikut (format JPG):
  - `windbreaker.jpg`
  - `nascar-jacket.jpg`
  - `jersey-polo.jpg`
  - `jersey-vintage.jpg`
  - `t-shirt.jpg`
  - `innersuit.jpg`
  - `riding-gloves.jpg`
  - `trekker-jacket.jpg`
  - `futsal-jersey.jpg`

Jika foto belum tersedia, website tetap menampilkan ilustrasi produk pengganti.

## Fitur
- Desain responsif untuk desktop dan ponsel
- Tema premium hitam dan emas
- Katalog produk dengan filter kategori
- Tombol konsultasi WhatsApp per produk
- Navigasi menu mobile
- Mode edit teks langsung di halaman dan ekspor HTML
